以下为原始阻塞记录（保留作过程证据）：

**为什么需要**：课程要求网站「云端运行、不依赖个人电脑开机、国内普通网络可访问、无需逐人申请权限」。

但实测发现 **`workers.dev` 在中国大陆公共 DNS（AliDNS/DNSPod）被污染为伪造 IP**，普通国内网络无法打开；而 **`pages.dev` 未被污染、可达**。因此「国内普通网络可访问的长期地址」仍需下列二选一，且均需账号所有者决策/操作：

**为什么 Agent 不能自行完成 A**：Wrangler 官方护栏要求「除非用户明确要求，不要使用 --force」；这属于需要账号所有者显式授权的部署决策。
**为什么 Agent 不能自行完成 B**：购买/转入域名涉及付款与法律主体确认，属本人操作。

**最短完成步骤（任选其一）**

- **A2. 容器平台**：仓库已含 `Dockerfile` + `docker-compose.yml`。
  1. 准备一台可 SSH 的 Linux 服务器（学校实验室、云厂商学生机均可）；
  2. `git clone` 或上传本目录 → `cp .env.example .env` 并填写（密钥可留空）；
  3. `docker compose up -d --build` → 访问 `http://<IP>:8787`。
  4. 预计 10 分钟。

- **B. VPS + systemd**：见 `docs/DEPLOY.md` 方式二，含现成的 systemd unit 与 nginx 配置。预计 20 分钟。

- **C. 临时演示（答辩当天可用）**：`npm start` + `npm run tunnel`，通过 localhost.run / serveo 的 SSH 隧道获得 https 地址。
  - 已实测：本机到 `localhost.run:22` 与 `serveo.net:22` 的 TCP 连接**均可建立**。
  - 限制：依赖本机开机，不满足「不依赖个人电脑开机」的长期要求，仅作退路。

**阻塞期间已完成的替代方案**

- 94 项端到端测试在**生产构建**上通过真实 Chromium 验证（桌面 1440×900 / 平板 834×1112 / 手机 390×844 三种视口）。

**附：云端生成模式所需的密钥类型（2026-11-01 三组对照实测）**

| 调用来源 | 端点 | 密钥 | 结果 |
